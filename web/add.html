An ESP32 on Wi-Fi

Plug it in over USB once. It stores the Wi-Fi and the hub address in its flash, then dials in by itself on any power supply.

docker run --rm --device /dev/ttyUSB0 --group-add "$(stat -c %g /dev/ttyUSB0)" {{.Data.Image}} \
  npx tsx src/cli.ts provision /dev/ttyUSB0 --ssid '<wifi name>' --pass '<wifi password>' \
  --hub {{.Data.NodesURL}} --key {{.Data.Key}}

A board on a computer's USB (Uno, Nano, any Synapse board)

A bridge beside the board carries it to the hub and redials if the link drops.

docker run -d --restart unless-stopped --device /dev/ttyACM0 --group-add "$(stat -c %g /dev/ttyACM0)" \
  -e SYNAPSE_NODE_KEY={{.Data.Key}} {{.Data.Image}} \
  npx tsx src/cli.ts bridge /dev/ttyACM0 --to {{.Data.NodesURL}}

On a Mac, Docker cannot reach USB: run the same command from a checkout of the harness with npm run synapse -- bridge …. A board with no Synapse firmware yet is flashed with npm run synapse -- flash <port> from the harness.
